# Обработка данных

Русификация работает внутри приложения Changan Qiyuan. Вход в аккаунт, состояние автомобиля и штатные функции продолжают использовать серверы Changan.

Дополнения русификации используют внешние сервисы:

- MyMemory — для неизвестного китайского текста публичных материалов и некоторых подписей вебстраниц;
- Яндекс — для отображения карты;
- Nominatim / OpenStreetMap — для определения адреса по координатам;
- GitHub — для проверки и скачивания обновлений русификации;
- DonationAlerts — после нажатия ссылки добровольной поддержки.

Переводчику передаётся сам текст, без cookies, данных авторизации и адреса исходной страницы. Вводимые значения полей не отправляются. Фильтр исключает текст с VIN, телефонами, email, длинными числовыми идентификаторами, паролями и кодами подтверждения.

Встроенные переводы доступны сразу. Успешные новые переводы сохраняются на телефоне. Удаление данных приложения удаляет этот кеш.

Удалённое OCR-распознавание баннеров в 1.0.0 отключено. Для отдельных изображений используются заранее подготовленные русские подписи.

Внешние сервисы работают по собственным правилам и могут быть временно недоступны.
